# Contributing

Thank you for your interest in contributing to GitOps Garage!

We welcome contributions that improve the platform, documentation or examples.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Commit your changes following conventional commit messages.
4. Open a Pull Request.
5. Wait for review.

## Commit Convention

Examples:

feat: add Tekton pipeline

fix: correct Helm values

docs: improve architecture documentation

refactor: simplify pipeline structure

## Reporting Issues

Please use GitHub Issues to report bugs, request features or suggest improvements.

## Code Style

- Keep manifests simple.
- Prefer readability over cleverness.
- Document important decisions.
- Everything should be reproducible.

Thank you for helping improve GitOps Garage!
